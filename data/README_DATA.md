# Data dictionary (ALL DATA IS SYNTHETIC)
Generated by `scripts/generate_data.py` (seed 42). Not hospital records; never present as a real pilot or real savings.
Demand (`quantity_requested`) is the original starter demand; everything else is simulated around it.

- **product_master.csv** - product, category, list price, preferred vendor, planned lead time, criticality (Vital/Essential/Desirable).
- **inventory_batches.csv** - one row per batch. `purchase_order_id` links to procurement (`OPENING` = stock on hand at start). `remaining_qty` at the end date = received - issued - expired. `status`: Active / Depleted / Expired.
- **stock_movements.csv** - the ledger. `movement_type`: OPENING, RECEIPT (+), ISSUE (-), EXPIRY_WRITE_OFF (-). Summing a batch's movements gives its `remaining_qty`.
- **consumption_transactions.csv** - daily requests per product. `quantity_issued` = what stock allowed; the difference is a stockout.
- **procurement_transactions.csv** - purchase orders. `delivery_date` is the actual arrival (or the promised date if `status` = In transit). Prices vary slightly around list price.

Important: the end date is 2026-11-10. Orders "In transit" are not yet stock.
